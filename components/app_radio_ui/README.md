# app_radio_ui

Portable C controller for the FM radio screen (`ui/main.json`, 480x480). The
same sources run on the device and in the native GSP simulator
(`host/platform_pc.c`). No ESP-IDF, FreeRTOS or audio code lives here.

## Screen and interactions

| Element | Behavior |
| --- | --- |
| Dial (drag) | An invisible full-width slider (`dial_jog`) acts as a jog wheel: one step (about 4.8 px) moves 0.1 MHz. Dragging right lowers the frequency. Release snaps to a station within 0.1 MHz and tunes it; otherwise playback stops ("Searching"). |
| `<<` / `>>` | Seek to the previous/next station, wrapping around the band. |
| Chips | Five stations around the current/nearest one; tap to tune. The centre chip turns amber when locked. |
| Play/pause | Toggles pause; the icon and status pill follow. |
| `Vol` | Cycles 20, 40, 60, 80, 100 %. |
| Status pill | Searching, Paused, No Wi-Fi, Connecting, Tuning, Playing or No signal. |

The scale strip `ui/dial_strip.png` is generated by `tools/gen_dial_strip.py`
from the station table; its 6 px per 0.1 MHz must match
`RADIO_TUNER_PX_PER_TENTH`.

## Structure

- `radio_tuner.c` (private): pure tuning state machine — frequency, jog,
  snap, seek, lock, committed station, volume. No GSP calls.
- `app_radio_ui.c`: binds the tuner to generated GSP helpers and forwards
  user intent to an `app_radio_ui_sink_t`.

## Contract

- **Create.** `app_radio_ui_create()` renders the initial state, starts a
  150 ms status timer, registers the event callback and calls `sink.set_volume`
  and `sink.tune` once before returning. `ui` and `sink.ctx` must outlive the
  controller.
- **Threading.** All controller state is owned by the GSP render task (event
  and timer callbacks). Sink callbacks run there and must not block; queue the
  work. `app_radio_ui_report()` is the only cross-task entry point: it
  atomically stores `{link, audio, station}` and the timer redraws the status
  within ~150 ms. Audio reports for a station other than the last one sent to
  `sink.tune` are treated as "Tuning".
- **Read.** `app_radio_ui_read()` returns a value snapshot; call it on the
  render task or after dispatch stops.
- **Destroy.** Quiesce GSP dispatch, then `app_radio_ui_destroy()` detaches
  the event callback, deletes the timer and frees the controller. On the
  device the controller lives until reboot.
- **Errors.** Setter failures are remembered in `last_error`; creation fails
  only when initial rendering or callback registration fails.

Dependencies: `esp-gsp` (public), `app_stations` (private).

```c
app_radio_ui_config_t cfg = {
    .initial_freq_tenths = 950, .initial_volume = 60,
    .sink = {.tune = on_tune, .set_paused = on_pause, .set_volume = on_volume},
};
app_radio_ui_handle_t radio;
ESP_ERROR_CHECK(app_radio_ui_create(ui, &cfg, &radio));
app_radio_ui_report(radio, APP_RADIO_LINK_ONLINE, APP_RADIO_AUDIO_PLAYING, 10);
```
